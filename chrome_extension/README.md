# 코코비즈 순위추적 (크롬 확장프로그램)

코코비즈 **순위 체크**에 등록한 상품의 네이버쇼핑 순위를 **내 크롬 브라우저에서**
측정해 코코비즈에 저장합니다.

## 왜 확장프로그램인가

서버나 PC 한 대가 모든 사용자의 순위를 재면 한 IP에 요청이 몰려 네이버가
2페이지부터 막습니다(2026-09-26 확인: 대기·감속을 해도 상위 40위만 읽힘).
사용자 각자의 브라우저에서 자기 항목만 재면 요청이 분산되고, 실제 사용자
세션이라 20페이지(800위)까지 정상으로 읽힙니다.

## 설치

1. 받은 zip 파일을 원하는 곳에 압축 해제합니다 (폴더는 지우지 마세요 — 지우면 확장프로그램도 사라집니다)
2. 크롬 주소창에 `chrome://extensions` 입력
3. 오른쪽 위 **개발자 모드** 켜기
4. **압축해제된 확장 프로그램을 로드합니다** → 압축 푼 폴더(`manifest.json`이 있는 폴더) 선택
5. 툴바의 퍼즐 아이콘에서 **코코비즈 순위추적**을 고정(📌)해 두면 편합니다

## 사용법

### 코코비즈 화면에서 (가장 간단)

1. 크롬에서 cocobiz.shop에 로그인합니다
2. 화면 오른쪽 아래에 **확장프로그램 순위 측정** 창이 뜹니다
3. **등록된 키워드 순위 측정**을 누릅니다
4. 끝나면 코코비즈 화면을 새로고침하면 순위 표에 반영됩니다

측정 창이 표를 가리면 오른쪽 위 **–**(줄이기: 제목줄만 남김) 또는 **×**(숨기기: 오른쪽 아래
작은 **순위 측정** 버튼만 남김)를 누르세요. 다른 메뉴로 가도 그 상태가 유지되고, 측정을 시작하면 다시 펼쳐집니다.

### 확장프로그램 아이콘에서

- **전체 측정 시작**: 위와 같습니다. 창을 닫아도 측정은 계속됩니다.
- **매일 자동 측정**: 체크 후 시각을 정하고 **자동 실행 저장**.
  크롬이 켜져 있을 때만 돕니다. 꺼져 있던 날은 다음에 크롬을 켤 때 한 번 실행됩니다.
  그날 이미 직접 측정했다면 자동 측정은 건너뜁니다.
- **확인할 페이지 수**: 1페이지 = 40위. 기본 10(400위). 많을수록 오래 걸립니다.
- **진단 시작**: 검색어 하나로 몇 페이지까지 읽히는지, 내 상품(상품번호·스토어명)이
  몇 위인지 바로 확인합니다. 코코비즈에 저장하지 않습니다.

## 자주 생기는 문제

| 증상 | 해결 |
|---|---|
| "쓸 수 있는 코코비즈 sid가 없습니다" | 코코비즈에 다시 로그인한 뒤, 주소에 `?sid=`가 보이는 화면을 열어둔 채 다시 시도 |
| "N페이지에서 중단 — 캡차" | 네이버쇼핑을 직접 열어 보안 확인을 한 번 풀고 다시 측정 |
| "페이지 미갱신" / "접근 제한" | 잠시(10분 이상) 뒤 다시 시도 |
| 코코비즈 화면에 측정 창이 안 뜸 | `chrome://extensions`에서 확장프로그램이 켜져 있는지 확인 후 코코비즈 새로고침 |

## 측정 기준

- 순위는 네이버 검색결과 데이터의 `rank` 값을 그대로 씁니다.
- **광고 자리는 순위로 치지 않습니다**(자연순위). 내 상품이 광고로도 떠 있으면 광고가 아닌 자리를 찾습니다.
- 광고 항목도 rank 값을 갖지만 자연순위와 무관한 번호입니다(2026-09-27 실측: 검색어 3개 모두
  광고 제외 시 1페이지 rank가 정확히 1~40, 광고 rank는 2~116으로 제각각). 예전 진단의 '1~54위'는 광고가 섞인 탓이었습니다.
- 확인한 범위 안에 없으면 **"N위 밖"**(예: 10페이지까지 봤으면 400위 밖)으로 저장됩니다.
  페이지가 실제로 넘어가지 않으면 거기서 멈추고 **실제로 본 곳까지만** 셉니다(3페이지에서 막히면 120위 밖).
  1페이지도 못 읽었으면(캡차 등) 아무것도 기록하지 않습니다.
- 내 상품 판별: 채널상품번호 / 상품 MID / 카탈로그 MID 중 하나가 같거나, 판매처명이 같으면 내 상품입니다.

## 개발 메모

- `background.js` 수정은 `chrome://extensions`에서 **새로고침(↻)** 해야 반영됩니다.
  팝업은 열 때마다 새로 읽히므로, 새로고침을 안 하면 화면과 로직 버전이 어긋납니다.
  진단 첫 줄의 `[확장 vX.Y.Z]`로 실제로 도는 버전을 확인하세요.
- 배포용 zip은 이 폴더의 파일만 담으면 됩니다(`manifest.json`이 zip 최상위에 오도록).
